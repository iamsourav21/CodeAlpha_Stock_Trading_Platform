# 📈 Stock Trading Platform

A desktop-based **Stock Trading Platform** built using **Core Java** and **Object-Oriented Programming (OOP)**. This application simulates a real-world stock market environment where users can buy and sell stocks, manage their portfolios, track profits/losses, and maintain transaction history.

This project was developed as part of a **Java Programming** course to demonstrate strong OOP principles, Java Collections, File Handling, Exception Handling, Multithreading, and GUI development using Java Swing.

---

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`


# ⚙️ How It Works

1. Register a new account.
2. Log in to the application.
3. Deposit funds into your wallet.
4. Browse available stocks.
5. Buy and sell stocks.
6. Track portfolio performance.
7. View transaction history.
8. Data is automatically saved using File Handling.
